# Table Format

一个 Obsidian 插件：选中表格中的若干单元格，把它们合并成一个(横向 colspan、纵向 rowspan 或矩形区域)；也可以把单个单元格分裂成几行几列。

## 合并语法

合并信息直接写在 Markdown 表格里，不依赖额外文件，没装插件时表格也能正常显示：

| 单元格内容 | 含义 |
| --- | --- |
| `<` | 与左边的单元格合并 |
| `^` | 与上边的单元格合并 |

示例：

```markdown
| 季度 | 产品     | <   | 备注 |
| ---- | -------- | --- | ---- |
| Q1   | 手机     | 120 | 旺季 |
| ^    | 平板     | 80  | ^    |
| Q2   | 合计 200 | <   | -    |
```

在实时预览和阅读视图中都渲染为：「产品」横跨 2 列，「Q1」和「旺季」纵跨 2 行，「合计 200」横跨 2 列。

## 使用方法

### 实时预览(推荐)

用鼠标拖选几个单元格，点右键，在菜单里选 **Merge cells**(中文界面显示「合并单元格」)。选区里有已合并的单元格时，菜单里还会出现 **Split cells**(「拆分单元格」)。

在某个单元格上点右键，选 **Split Cell…**(中文界面显示「分裂单元格…」)，在弹出的窗口里填要分成几行、几列，点「分裂」(或按回车)。想撤回时，拖选分裂出来的那几个单元格，点右键选 **取消分裂**(英文界面显示「Unsplit cells」)，就会合并回一个单元格，并删掉分裂时插入的行和列。

### 命令和面板

1. 把光标放进表格。
2. 选择单元格，二选一：
   - **在编辑器里直接选中**：拖选一段从某个单元格到另一个单元格的文字(源码模式下最方便)，执行命令「合并选中的单元格」。
   - **用面板选**：执行命令「打开单元格合并面板」，或在表格上点右键选「合并单元格…」，在弹出的网格里用鼠标或手指拖选，也可以先点一个单元格再按住 Shift 点另一个，然后点「合并」。
3. 想取消合并时，选中已合并的单元格，执行「拆分单元格(取消合并)」，或在面板里点「拆分」。
4. 想把一个单元格分裂成几行几列时，把光标放进这个单元格，执行「分裂单元格(拆成几行几列)」，或在表格上点右键选「分裂单元格…」。

| 命令 | 作用 |
| --- | --- |
| 合并选中的单元格 | 选区跨了多个单元格时直接合并，否则打开面板 |
| 打开单元格合并面板 | 打开网格选择面板 |
| 拆分单元格(取消合并) | 拆开选区涉及的所有合并区域 |
| 分裂单元格(拆成几行几列) | 把光标所在的单元格分成指定的行数和列数 |
| 取消分裂(恢复成一个单元格) | 把选中的分裂单元格合并回一个，并删掉分裂时插入的行和列 |
| 对齐表格列宽 | 按显示宽度对齐源码中的列(中文算两个字符) |

可以在「设置 → 快捷键」里给这些命令绑定快捷键。

### 规则

- 选区碰到已合并的区域时，会自动扩大到包含整个区域，所以可以在已有合并的基础上继续合并。
- 被合并的单元格里有文字时，默认用空格拼接后放进左上角单元格；在设置里可以改成用 `<br>` 换行拼接，或只保留左上角的内容。
- 表头行可以横向合并，但不能和正文行纵向合并(HTML 表格的表头和正文是分开的)。
- 分裂单元格时，原单元格占的行数 / 列数不够，就在它下方插入新行、右侧插入新列；同一行、同一列的其他单元格会自动合并跨过新插入的部分，所以表格其余部分看起来不变。原来的内容留在左上角。
- 分裂一个已合并的单元格时，先用它已经占的行列；例如 2 行 × 4 列的合并单元格分成 1 行 × 2 列，得到两个各占 2 行 × 2 列的单元格，不插入新行列。
- 表头单元格只能按列分裂，不能按行分裂；每个方向最多分成 20 份。
- 「取消分裂」不依赖操作记录，而是看表格结构：选区合并后，里面有哪些行或列只是在延续合并、删掉也不影响显示，就把它们删掉。所以保存、重启之后也能用；分裂后在小格里填的文字会按「合并时的内容处理」设置拼接。只选中其中几格时，只撤回这几格。
- 分裂没有插入新行列时(例如把合并单元格重新分配)，菜单里不会出现「取消分裂」，直接用「合并单元格」就能恢复。刚分裂完也可以直接按 Ctrl/Cmd+Z 撤销。
- 合并后的内容默认水平、垂直居中；在设置里关闭「合并单元格内容居中」后，沿用所在列的对齐方式(`:---`、`:---:`、`---:`)。

## 已知限制

- 需要 Obsidian 1.6.0 及以上版本。
- 实时预览中，用 Tab 或方向键进入被合并的单元格时，这张表会暂时显示原始网格(能看到 `<` / `^`)，方便编辑；离开后恢复合并显示。设置里可以关闭实时预览的合并显示。
- 源码模式中始终显示原始的 `<` / `^` 标记。
- 实时预览的合并显示和右键菜单依赖 Obsidian 表格编辑器的内部实现(已在 Obsidian 1.6.7 中实测，并对照 1.14.4 的源码核实)，以后的 Obsidian 版本可能会变。
- 单元格内容如果恰好只有一个 `<` 或 `^`，会被当作合并标记。

## 安装

### 从 Release 下载

1. 打开 [Releases](https://github.com/Thinker746/obsidian-table-format/releases)，下载最新版本的 `table-format-<版本号>.zip`。
2. 解压到库目录下的 `.obsidian/plugins/`，得到 `.obsidian/plugins/table-format/`(里面有 `main.js`、`manifest.json`、`styles.css`)。
   注意：zip 里已经带有 `table-format/` 文件夹，不要再解压到 `plugins/table-format/` 里面，否则会变成 `plugins/table-format/table-format/main.js`，Obsidian 读不到新文件。
3. 重启 Obsidian 或在「设置 → 第三方插件」中刷新，然后启用 **Table Format**。更新插件后，要先关闭再重新启用插件(或重启 Obsidian)，新版本才会生效。

也可以用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件，填入 `Thinker746/obsidian-table-format`，自动安装和更新。

### 从源码构建

```bash
npm install
npm run build
```

把 `main.js`、`manifest.json`、`styles.css` 复制到 `.obsidian/plugins/table-format/`。

### 开发

```bash
npm run dev    # 监听源码变化并重新构建
npm test       # 运行单元测试
```

### 发布新版本

```bash
npm version patch   # 或 minor / major：同步更新 manifest.json、versions.json，并打上标签
git push --follow-tags
```

推送标签后，GitHub Actions 会运行测试、构建，并创建 Release(附带 `main.js`、`manifest.json`、`styles.css` 和打包好的 zip)。

也可以不打标签，直接在 GitHub 上手动发布：Actions → Release → Run workflow。工作流会按 `manifest.json` 里的版本号创建标签和 Release。
